# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。

# 光储共用并网点仲裁

设备清单新增 `kind`：`pv`（光伏，缺省）、`bess`（储能电池）、`meter`（并网点表计）。电池遥测约定充电为负、放电为正；表计上网功率非负。电池与表计无辐照通道，空辐照列按缺测处理而非隔离。储能或表计设备存在时，M7 储能仲裁才产出片段；纯光伏场该模块为空且不阻断归档。

每个左值采样区间同时并列三个功率并折算电量：光伏发电 `pv_kwh`、电池充电 `charge_kwh`（吸收）、电池放电 `discharge_kwh`（释放）、上网 `export_kwh`。自然净出口 `natural_kwh = pv_kwh − charge_kwh + discharge_kwh`，账差 `residual_kwh = natural_kwh − export_kwh`。每段都必须由这三个量相互解释，解释不了的片段留待查，不填 0、不并入结算。

认定原因码：`GRID_CURTAIL`（自然净出口超并网限值 `export_limit_kw` 且实测上网落在限值计量带内，按约束缺口 `max(natural−限值电量,0)` 认定可申报）；`NO_LOSS`（约束未生效且账差在容差内）；`PV_OWN_LOSS`（约束未生效但光伏自身减发，不可申报）；`OVER_DELIVER`（实测上网高于限值带或自然净出口，待查）；`BALANCE_FAIL`（账差超过 `storage_tolerance_kwh`，待查）；`DATA_GAP`（任一关键量缺测，待查）。

电池充放量在任何原因码下都不计入限发：净差法 `max(pv_kwh−export_kwh,0)` 会把充电误判为限电、被放电冲减真实损失，仅作为 `naive_claim_kwh` 对照展示；`battery_impact_kwh = naive_claim_kwh − claimable_kwh` 量化两者差额。待查片段的可申报量不参与汇总。

上游充放/限值依据通过 `POST /api/runs/{run_id}/basis` 进入版本账本：同内容依据重试返回 `changed=false` 且不新增版本；校验失败（负值、同一依据同时充放、超电池额定 1.2 倍、未知字段、空依据、纯光伏批）整体回滚，旧版依据与现场凭据原样保留。首跑规则结果记为 r0，第一条上游依据为 r1，每次重算只替换受影响片段并在片段上标注 `basis_revision`，未受影响片段电量不动。片段 `battery_source` 区分 `telemetry`（现场遥测）、`basis`（上游依据覆盖）与 `gap`（缺测）：充放依据只替换已有电池遥测的槽位，缺测槽位绝不臆造，仍按 DATA_GAP 待查；现场原始记录不被改写，依据只作用于重算结果。依据历史随导出包 `storage_adjudication.json` 一并封存。
